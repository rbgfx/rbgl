A software renderer written for Ruby

Graphics, one pixel at a time—in Ruby.

Build a graphics pipeline, shade pixels, and open native windows without leaving the language you already know.

A graphics pipeline you can read.

RBGL keeps the rendering path visible. Define vertices and shaders in Ruby, then inspect the framebuffer as ordinary data.

  1. Vertex dataTyped layouts for positions, colors, normals, and UVs.
  2. Ruby shadersVertex and fragment stages expressed as Ruby blocks.
  3. RasterizationTriangles, lines, points, depth testing, and alpha blending.
  4. Present or exportShow a native window or write frames in headless CI.

The frame loop stays Ruby.

The same drawing code can render to a file on a CI runner or open a native window on macOS and Linux.

Read the quick start 
require "rbgl"

window = RBGL::GUI::Window.new(
  width: 800, height: 600,
  backend: :auto
)

window.run do |context, _delta_time|
  context.clear(color: Color.from_hex("#0f172a"))
  context.bind_pipeline(pipeline)
  context.bind_vertex_buffer(vertices)
  context.draw_arrays(:triangles, 0, 3)
end
